# Ответ к задаче 2.2: Копирование объекта

**Ожидаемый вывод:**

```
Oleg
```

**Объяснение:**
Объекты копируются по ссылке. Изменение свойства через одну переменную отражается на всех переменных, ссылающихся на этот объект.

💡 **Важно:** В отличие от примитивных типов, объекты в JavaScript передаются по ссылке, а не по значению. Это одна из фундаментальных особенностей языка.
