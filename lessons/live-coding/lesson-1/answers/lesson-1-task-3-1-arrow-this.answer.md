# Ответ к задаче 3.1: this в стрелочной функции

**Ожидаемый вывод:**

```
Hi, I'm undefined
```

**Объяснение:**
[**Стрелочные функции**]({{ site.baseurl }}/glossary/lesson-2-glossary#стрелочные-функции) не имеют собственного `this` и берут его из внешнего контекста. В данном случае это глобальный объект, где `name` не определено.

💡 **Важно:** Это ключевое отличие стрелочных функций от обычных - они наследуют `this` из внешней области видимости.
