# Ответ к задаче 2.1: Копирование примитива

**Ожидаемый вывод:**

```
5
```

**Объяснение:**
Примитивные значения копируются по значению. Изменение переменной `b` не влияет на переменную `a`.

💡 **Важно:** Примитивные типы данных (number, string, boolean, null, undefined, symbol, bigint) всегда передаются и копируются по значению, в отличие от объектов, которые передаются по ссылке.
