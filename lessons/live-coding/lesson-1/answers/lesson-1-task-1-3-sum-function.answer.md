# Ответ к задаче 1.3: Реализация функции суммы

**Пример решения:**

```js
function sum(a, b) {
  return a + b;
}
```

**Пояснение:**
В этой задаче важно самостоятельно реализовать функцию, которая принимает два аргумента и возвращает их сумму. Это базовый навык для понимания работы с функциями и параметрами в JavaScript. Используйте `let` или `const` для объявления переменных, если они понадобятся внутри функции.
