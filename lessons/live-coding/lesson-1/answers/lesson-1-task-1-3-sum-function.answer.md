# Ответ к задаче 1.3: Реализация функции суммы

**Пример решения:**

```js
function sum(a, b) {
  return a + b;
}
```

💡 **Альтернативные способы:**

Используя [**стрелочную функцию**]({{ site.baseurl }}/glossary/lesson-2-glossary#стрелочные-функции){:data-glossary-term="Стрелочные функции" data-glossary-definition="Краткий синтаксис функций"}:
```js
const sum = (a, b) => a + b;
```
