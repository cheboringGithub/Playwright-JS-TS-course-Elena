# Ответ к задаче 3.2: this в обычной функции

**Ожидаемый вывод:**

```
Hi, I'm Ivan
```

**Объяснение:**
В обычной функции `this` ссылается на объект, через который вызвана функция. В данном случае — на объект `person`.

💡 **Важно:** В отличие от [**стрелочных функций**]({{ site.baseurl }}/glossary/lesson-2-glossary#стрелочные-функции), обычные функции имеют собственный `this`, который определяется тем, как функция была вызвана.
