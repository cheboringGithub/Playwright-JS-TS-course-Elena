# Ответ к задаче 2.2: Promise методы

**Ожидаемый вывод:**

```
Race результат: Быстрый
All результаты: ['Быстрый', 'Медленный']
AllSettled результаты: [
  {status: 'fulfilled', value: 'Быстрый'},
  {status: 'fulfilled', value: 'Медленный'},
  {status: 'rejected', reason: 'Ошибка'}
]
```

**Объяснение работы методов Promise:**

### 1. **Promise.race() - "Кто первый?"**
```javascript
Promise.race([fastPromise, slowPromise, errorPromise])
```
- Возвращает результат **первого** завершившегося Promise
- В нашем случае `fastPromise` завершается через 100мс первым
- **Результат:** `"Быстрый"` (успешный Promise)
- **Важно:** Если первым завершится `errorPromise`, результат будет ошибкой

### 2. **Promise.all() - "Все или ничего"**
```javascript
Promise.all([fastPromise, slowPromise])
```
- Ждет завершения **всех** Promise
- Возвращает массив результатов в том же порядке
- **Результат:** `['Быстрый', 'Медленный']`
- **Особенность:** Если любой Promise завершится с ошибкой, весь `Promise.all` завершится с ошибкой

### 3. **Promise.allSettled() - "Все с результатами"**
```javascript
Promise.allSettled([fastPromise, slowPromise, errorPromise])
```
- Ждет завершения **всех** Promise (успешных и неуспешных)
- Возвращает массив объектов с результатами каждого Promise
- **Результат:** Массив с объектами, содержащими `status` и `value`/`reason`

**Сравнение методов:**

| Метод | Поведение | Когда завершается | Результат |
|-------|-----------|------------------|-----------|
| `Promise.race()` | Первый завершившийся | Как только один Promise завершится | Результат первого |
| `Promise.all()` | Все успешные | Когда все Promise успешно завершатся | Массив результатов |
| `Promise.allSettled()` | Все (любого статуса) | Когда все Promise завершатся | Массив статусов |

**Практическое применение:**
- **race()** - таймауты, выбор самого быстрого API
- **all()** - параллельная загрузка данных, где нужны все
- **allSettled()** - логирование результатов всех операций
