# Ответ к задаче 3.2: Обработка ошибок

**Ожидаемый вывод:**

```
Ошибка перехвачена: Ошибка загрузки данных
Результат 1: Значение по умолчанию
Поймана ошибка: Ошибка в try блоке
Результат 2: Данные обработаны
```

**Объяснение обработки ошибок в async/await:**

### 1. **Обработка ошибок без try-catch (через .catch())**
```javascript
const result1 = await fetchData().catch(error => {
  console.log('Ошибка перехвачена:', error.message);
  return 'Значение по умолчанию';
});
```
- `fetchData()` выбрасывает ошибку
- `.catch()` перехватывает ошибку и возвращает альтернативное значение
- **Результат:** `"Значение по умолчанию"`

### 2. **Обработка ошибок с try-catch**
```javascript
async function fetchDataWithTryCatch() {
  try {
    throw new Error('Ошибка в try блоке');
  } catch (error) {
    console.log('Поймана ошибка:', error.message);
    return 'Данные обработаны';
  }
}
```
- Ошибка выбрасывается внутри `try` блока
- `catch` перехватывает ошибку и логирует её
- Функция возвращает альтернативное значение
- **Результат:** `"Данные обработаны"`

### 3. **Вызов функции с try-catch**
```javascript
const result2 = await fetchDataWithTryCatch();
```
- Функция уже обработала ошибку внутри себя
- Возвращает успешный результат
- **Результат:** `"Данные обработаны"`

**Сравнение способов обработки ошибок:**

| Способ | Синтаксис | Когда использовать | Преимущества |
|--------|-----------|-------------------|--------------|
| **.catch()** | `await promise.catch(handler)` | Простая обработка одной ошибки | Краткость, цепочка методов |
| **try-catch** | `try { await promise } catch(error) {}` | Сложная логика обработки | Полный контроль, множественные операции |

**Практические примеры в тестировании:**

### **Обработка ошибок загрузки страницы:**
```javascript
try {
  await page.goto('https://example.com');
} catch (error) {
  console.log('Страница не загрузилась:', error.message);
  // Альтернативная логика
}
```

### **Обработка ошибок поиска элемента:**
```javascript
const element = await page.$('.button').catch(() => {
  console.log('Кнопка не найдена, используем альтернативную');
  return page.$('.alternative-button');
});
```

### **Обработка ошибок API:**
```javascript
const response = await page.waitForResponse(/api\/data/).catch(error => {
  console.log('API не ответил:', error.message);
  return null;
});
```

**Ключевые принципы:**
1. **Всегда обрабатывайте ошибки** в асинхронном коде
2. **Выбирайте способ** в зависимости от сложности логики
3. **Предоставляйте fallback** значения для критических операций
4. **Логируйте ошибки** для отладки
