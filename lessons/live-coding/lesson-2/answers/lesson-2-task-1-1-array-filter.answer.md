# Ответ к задаче 2.1: Чётные числа (filter)

```js
function getEvenNumbers(arr) {
  return arr.filter(num => num % 2 === 0);
}
```

**Пояснение:**
Метод `filter` возвращает новый массив, включающий только те элементы, для которых функция-коллбек возвращает true. В данном случае — только чётные числа.
