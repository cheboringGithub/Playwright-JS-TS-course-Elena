# Ответ к задаче 2.1: Чётные числа (filter)

```js
function getEvenNumbers(arr) {
  return arr.filter(num => num % 2 === 0);
}
```

**Пояснение:**
- Используем [**метод массива `filter`**]({{ site.baseurl }}/glossary/lesson-2-glossary#методы-массивов){:data-glossary-term="filter" data-glossary-definition="Метод массива, создающий новый массив с элементами, прошедшими проверку в callback-функции" data-glossary-category="JavaScript"}, чтобы пройти по всем элементам массива и вернуть только те, которые удовлетворяют условию.
- В данном случае условие — число делится на 2 без остатка (`num % 2 === 0`), то есть чётное.
- В результате получаем новый массив только с чётными числами, исходный массив не изменяется.
- Такой подход часто используется для фильтрации данных по любому критерию.

💡 **Важно:** Используется [**стрелочная функция**]({{ site.baseurl }}/glossary/lesson-2-glossary#стрелочные-функции) для краткости записи условия.
