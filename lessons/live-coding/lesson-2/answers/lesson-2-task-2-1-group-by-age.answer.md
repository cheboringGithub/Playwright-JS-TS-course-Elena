# Ответ к задаче 2.1: Группировка по возрасту

```js
function groupByAge(users) {
  return users.reduce((acc, {name, age}) => {
    acc[age] = acc[age] || [];
    acc[age].push(name);
    return acc;
  }, {});
}
```

**Пояснение:**
- Используем [**метод массива `reduce`**]({{ site.baseurl }}/glossary/lesson-2-glossary#методы-массивов){:data-glossary-term="reduce" data-glossary-definition="Метод агрегации данных массива"}, чтобы пройти по всем пользователям и собрать объект, где ключ — возраст, а значение — массив имён.
- Внутри reduce используем [**деструктуризацию**]({{ site.baseurl }}/glossary/lesson-2-glossary#деструктурирующее-присваивание) объекта пользователя на `name` и `age`.
- Если для возраста ещё нет массива, создаём его: `acc[age] = acc[age] || []`.
- Добавляем имя пользователя в соответствующий массив.
- В результате получаем объект, где по каждому возрасту собраны имена всех пользователей этого возраста.
- Такой подход позволяет легко группировать любые данные по нужному критерию.
