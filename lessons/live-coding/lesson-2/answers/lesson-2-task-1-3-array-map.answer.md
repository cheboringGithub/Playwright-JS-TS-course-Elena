# Ответ к задаче 2.3: Квадраты элементов (map)

```js
function squareArray(arr) {
  return arr.map(x => x * x);
}
```

**Пояснение:**
Метод `map` возвращает новый массив, в котором каждый элемент — результат вызова переданной функции для соответствующего элемента исходного массива.
