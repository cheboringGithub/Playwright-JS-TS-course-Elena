# Ответ к задаче 2.2: Сумма заказов по пользователям

```js
function getOrdersSummary(orders) {
  return orders.reduce((acc, {user, amount}) => {
    acc[user] = (acc[user] || 0) + amount;
    return acc;
  }, {});
}
```

**Пояснение:**
- Используем `reduce`, чтобы пройти по всем заказам и собрать объект, где ключ — имя пользователя, а значение — сумма его заказов.
- Внутри reduce деструктурируем каждый заказ на `user` и `amount`.
- Для каждого пользователя накапливаем сумму: если пользователь встречается впервые, начальное значение 0.
- К каждому пользователю прибавляем сумму текущего заказа.
- В результате получаем объект, где для каждого пользователя указана общая сумма его заказов.
- Такой подход часто используется для агрегации данных по ключу.
