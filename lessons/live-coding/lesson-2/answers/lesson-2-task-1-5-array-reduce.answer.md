# Ответ к задаче 2.5: Сумма элементов массива (reduce)

```js
function sumArray(arr) {
  return arr.reduce((acc, curr) => acc + curr, 0);
}
```

**Пояснение:**
[**Метод `reduce`**]({{ site.baseurl }}/glossary/lesson-2-glossary#методы-массивов){:data-glossary-term="reduce" data-glossary-definition="Сворачивает массив к одному значению"} позволяет "свернуть" массив к одному значению, последовательно применяя функцию к каждому элементу и аккумулятору.

💡 **Параметры:** `acc` (аккумулятор) — накапливает результат, `curr` (текущий элемент) — текущий элемент массива, `0` — начальное значение аккумулятора.
