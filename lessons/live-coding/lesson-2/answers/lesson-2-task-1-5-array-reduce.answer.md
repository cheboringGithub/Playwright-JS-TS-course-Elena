# Ответ к задаче 2.5: Сумма элементов массива (reduce)

```js
function sumArray(arr) {
  return arr.reduce((acc, curr) => acc + curr, 0);
}
```

**Пояснение:**
Метод `reduce` позволяет "свернуть" массив к одному значению, последовательно применяя функцию к каждому элементу и аккумулятору.
