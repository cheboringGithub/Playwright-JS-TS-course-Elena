# Глоссарий к уроку 5: Асинхронность в JavaScript

---

## А

### Асинхронность {#асинхронность}
**Что это:** Способ выполнения операций, при котором код не ждет завершения текущей задачи перед переходом к следующей.

**Зачем нужна:** Позволяет выполнять несколько операций одновременно, не блокируя основной поток выполнения.

**Основные принципы:** Нелинейный порядок выполнения, параллельная обработка задач, использование колбэков, промисов или async/await.



**Пример:**
```javascript
// Синхронный код - блокирует выполнение
console.log('Начинаем загрузку');
const result = fetch('/api/data'); // Ждем завершения
console.log('Загрузка завершена');

// Асинхронный код - не блокирует
console.log('Начинаем загрузку');
fetch('/api/data').then(data => {
  console.log('Данные получены:', data);
});
console.log('Загрузка запущена, но не ждем завершения');

// Результат выполнения:
// "Начинаем загрузку"
// "Загрузка запущена, но не ждем завершения" 
// "Данные получены: [данные]"
```

## К

### Колбэк (Callback) {#колбэк-callback}
**Что это:** Функция, которая передается как аргумент другой функции и выполняется после завершения определенной операции.

**Зачем нужен:** Обеспечивает выполнение кода после завершения асинхронной задачи.

**Основные принципы:** Передача функции как параметра, выполнение в будущем, основа асинхронного программирования.



**Пример:**
```javascript
// Простой колбэк - выполнится через 1 секунду
setTimeout(() => {
  console.log('Привет! Это сообщение появится через 1 секунду');
}, 1000);

console.log('Это сообщение появится сразу');

// Колбэк с параметрами - загружаем пользователя
function loadUser(id, callback) {
  // Имитируем загрузку данных
  setTimeout(() => {
    const user = { id: id, name: 'Иван', email: 'ivan@example.com' };
    callback(user); // Вызываем колбэк с данными
  }, 2000);
}

// Используем колбэк
loadUser(123, (user) => {
  console.log('Пользователь загружен:', user.name);
  console.log('Email:', user.email);
});

console.log('Загрузка пользователя запущена...');

// Результат выполнения:
// "Это сообщение появится сразу"
// "Загрузка пользователя запущена..."
// "Привет! Это сообщение появится через 1 секунду"
// "Пользователь загружен: Иван"
// "Email: ivan@example.com"
```

## П

### Promise {#promise}
**Что это:** Объект, представляющий результат асинхронной операции, которая может завершиться успешно или с ошибкой.

**Зачем нужен:** Упрощает работу с асинхронным кодом, предоставляет удобные методы для обработки результатов.

**Основные принципы:** Три состояния (pending, fulfilled, rejected), цепочка методов .then() и .catch(), статические методы для групповых операций.



**Пример:**
```javascript
// Создание Promise - бросаем монетку
const coinFlip = new Promise((resolve, reject) => {
  setTimeout(() => {
    const random = Math.random();
    if (random > 0.5) {
      resolve('Орел! Монетка упала орлом вверх');
    } else {
      reject('Решка! Монетка упала решкой вверх');
    }
  }, 1000);
});

console.log('Бросаем монетку...');

// Использование Promise
coinFlip
  .then(result => {
    console.log('Успех:', result);
  })
  .catch(error => {
    console.log('Результат:', error);
  });

// Promise.all для параллельного выполнения
const promise1 = new Promise(resolve => setTimeout(() => resolve('Первая задача'), 1000));
const promise2 = new Promise(resolve => setTimeout(() => resolve('Вторая задача'), 2000));

Promise.all([promise1, promise2]).then(results => {
  console.log('Все задачи выполнены:', results);
});

// Результат выполнения:
// "Бросаем монетку..."
// "Успех: Орел! Монетка упала орлом вверх" (или "Результат: Решка!...")
// "Все задачи выполнены: ['Первая задача', 'Вторая задача']"
```

## A

### Async/Await {#async-await}
**Что это:** Синтаксический сахар над Promise, позволяющий писать асинхронный код в синхронном стиле.

**Зачем нужен:** Упрощает чтение и понимание асинхронного кода, упрощает обработку ошибок.

**Основные принципы:** Ключевое слово async для функций, await для ожидания промисов, автоматическое возвращение Promise.



**Пример:**
```javascript
// Функция async всегда возвращает Promise
async function getUserData(id) {
  try {
    // Имитируем загрузку данных пользователя
    await new Promise(resolve => setTimeout(resolve, 1000));
    
    if (id === 123) {
      return { id: 123, name: 'Иван', email: 'ivan@example.com' };
    } else {
      throw new Error('Пользователь не найден');
    }
  } catch (error) {
    console.error('Ошибка загрузки:', error.message);
    throw error;
  }
}

// Использование async/await
async function main() {
  try {
    console.log('Начинаем загрузку пользователя...');
    const user = await getUserData(123);
    console.log('Пользователь загружен:', user.name);
    console.log('Email:', user.email);
  } catch (error) {
    console.log('Не удалось загрузить пользователя');
  }
}

// Запускаем
main();

// Результат выполнения:
// "Начинаем загрузку пользователя..."
// "Пользователь загружен: Иван"
// "Email: ivan@example.com"
```

## E

### Event Loop {#event-loop}
**Что это:** Механизм JavaScript, который координирует выполнение синхронного и асинхронного кода.

**Зачем нужен:** Обеспечивает неблокирующее выполнение асинхронных операций, управляет очередями задач.

**Основные принципы:** Бесконечный цикл, проверка очередей задач, приоритет микрозадач над макрозадачами.



**Пример:**
```javascript
console.log('1. Начинаем выполнение'); // Синхронный код

setTimeout(() => {
  console.log('4. Макрозадача выполнена'); // Макрозадача
}, 0);

Promise.resolve().then(() => {
  console.log('3. Микрозадача выполнена'); // Микрозадача
});

console.log('2. Синхронный код завершен'); // Синхронный код

// Результат выполнения:
// "1. Начинаем выполнение"
// "2. Синхронный код завершен"
// "3. Микрозадача выполнена"
// "4. Макрозадача выполнена"

// Порядок выполнения Event Loop:
// 1. Синхронный код (1, 2)
// 2. Микрозадачи (3) - Promise
// 3. Макрозадачи (4) - setTimeout
```

## Т

### Таймаут (Timeout) {#таймаут-timeout}
**Что это:** Максимальное время ожидания завершения асинхронной операции.

**Зачем нужен:** Предотвращает бесконечное ожидание, обеспечивает контроль над временем выполнения тестов.

**Основные принципы:** Установка временных ограничений, обработка превышения времени, retry логика.



**Пример:**
```javascript
// Создаем Promise с таймаутом
const timeoutPromise = new Promise((_, reject) => {
  setTimeout(() => reject('Время ожидания истекло!'), 3000);
});

// Имитируем загрузку данных
const loadDataPromise = new Promise((resolve) => {
  setTimeout(() => {
    resolve('Данные успешно загружены!');
  }, 2000); // Загрузится через 2 секунды
});

// Используем Promise.race - что выполнится первым
Promise.race([
  loadDataPromise,    // Загрузится через 2 секунды
  timeoutPromise      // Истечет через 3 секунды
]).then(result => {
  console.log('Успех:', result);
}).catch(error => {
  console.log('Ошибка:', error);
});

// Результат выполнения:
// "Успех: Данные успешно загружены!"
// (данные загрузились быстрее, чем истек таймаут)

// Если бы loadDataPromise выполнялся дольше 3 секунд,
// то результат был бы: "Ошибка: Время ожидания истекло!"
```
