## 💡 Как пользоваться глоссарием

1. **Навигация по урокам** — используйте ссылки выше для перехода к терминам конкретного урока
2. **Алфавитный поиск** — найдите нужный термин в алфавитном указателе
3. **Перекрестные ссылки** — внутри определений есть ссылки на связанные понятия
4. **Примеры кода** — каждое определение содержит практические примеры
5. **Возврат к урокам** — в каждом разделе есть ссылка для возврата к соответствующему уроку
